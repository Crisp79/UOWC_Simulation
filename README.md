## UOWC Simulator

### Prerequisites
Ensure you have [uv](https://github.com/astral-sh/uv) installed on your system.

- After unzipping the folder, run the following in terminal from the project directory
```
uv sync
```

For UOWC single layer results, run the following
```
uv run main.py
```

For TOWC results, run the following
```
uv run towc.py
```

For multiaperture results, run the following
```
uv run iid_multiaperture.py
```
